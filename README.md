# PM3D-2526-MorseCodeTyper

## Abstract

Se numește defapt Telegraph Key, dar nu ar fi un proiect de al meu dacă nu aș începe prin a da numele greșit. Ideea este simplă: un braț mult prea complicat v-a fi apăsat de către utilizator, în funcție de lungimea apăsării vom avea 3 cazuri: spațiu, punct, sau linie. Apăsarea brațului v-a avea 2 efecte: v-a coborâ o ștampilă care v-a scrie codul, și v-a mișca foalia în stânga cu o căsuță ca să permită scrierea unui semn nou.

De ce am ales să fac acestă contrapție? Simplu! O mașină de scris mi se părea prea complicat, această alternativă părea mult mai simplă.
